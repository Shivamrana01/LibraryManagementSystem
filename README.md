
# Library Management System

A beginner-friendly Library Management System developed using Java.
This project helps manage books through a simple console-based application.

## Features

- Add new books
- View all books
- Search books by ID
- Issue books
- Return books
- Check book availability
- Prevent duplicate book IDs

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Switch statements and loops

## Project Structure

```text
LibraryManagementSystem/
├── LibraryManagementSystem.java
└── README.md
```

## How to Run

### 1. Compile the program

```bash
javac LibraryManagementSystem.java
```

### 2. Run the program

```bash
java LibraryManagementSystem
```

## How It Works

1. Select an option from the menu.
2. Add a book using its ID, title, and author.
3. View or search for books.
4. Issue an available book.
5. Return an issued book.
6. Exit the application.

## Current Limitations

- Book records are stored in memory.
- Records are lost when the program exits.
- File handling and permanent storage can be added in a future version.

## Learning Outcomes

- Practiced Java classes and objects.
- Learned to use ArrayList for storing records.
- Applied loops, methods, and conditional statements.
- Practiced basic menu-driven application development.
